# 폴짝 랜딩 그림 교체 (짧은 설계)

승인: 대표, 2026-11-26.

## 목적

폴짝 1.1.0이 2026-11-26에 출시됐다. 대표가 맘카페, 당근, 카톡에 홍보글을 올리면 사람들은 poljjak.lunenlabs.com으로 들어온다. 그 사람들이 앱스토어 1.1.0과 같은 내용을 보고, 히어로의 가족 그림(Canva)과 같은 화풍의 그림을 보게 한다.

## 바꾸는 것 (`src/poljjak/Landing.tsx`, `public/poljjak/img/`)

- 제목: "나들이 끝나면 스토리 각 📸" → "이번 주말, 아이랑 어디 가지?". 이모지는 쓰지 않는다.
- 부제: 가까운 놀이터·키즈카페·어린이 공연을 한눈에, 다녀온 나들이는 기록으로.
- 가족 그림(`family.jpg`)은 그대로 둔다.
- App Store 버튼 아래에 한 줄을 넣는다: 회원가입 없이 · 기록은 내 폰에만. 기존 🔒 카드 내용을 옮긴 것이다.
- 스토리 카드 예시: 동그라미 얼굴 placeholder를 Canva 그림으로 바꾼다.
- 기능 카드 4개를 1.1.0 기준으로 바꾸고, 이모지 대신 그림을 쓴다. 그림 칸은 44px에서 72px 안팎으로 키운다.
  1. 놀이터·키즈카페 지도: 아이, 미끄럼틀, 지도 핀
  2. 어린이 공연·축제: 작은 무대, 인형극, 풍선
  3. 같이 놀자: 손잡은 두 아이
  4. 나들이 기록: 발자국 길과 사진 한 장
- 문구는 Poljjak `docs/store/app-store-ko.md`에서 가져온다. 앱에 있는 기능만 쓰고, 최상급 표현과 `src/copy/bannedWords.ts`의 금지어는 쓰지 않는다. 말투는 "~해요".

## 방법

검토한 방법은 세 가지다. A는 Canva AI로 생성, B는 직접 그린 SVG, C는 대표가 Canva 라이브러리에서 고르기. 대표는 A를 골랐다. 히어로 그림이 Canva 그림이라 화풍이 가장 잘 맞기 때문이다. Canva 크레딧이 없으면 멈추고, B로 갈지 대표에게 묻는다.

1. 그림마다 Canva AI로 후보 2~3개를 만든다. 화풍은 family.jpg에 맞춘다: 파스텔, 둥근 선, 노랑·하늘·초록.
2. 대표가 고른다.
3. 고른 그림을 웹용으로 다듬는다. 정사각형 그림은 칸 크기의 2배(약 160px)와 3배로, 스토리 카드는 720x1280으로 만든다.
4. 페이지를 고치고, 로컬에서 화면을 찍어 보여 준다. 그다음 PR을 올리고, 병합은 대표가 한다.

앱 코드, 개인정보처리방침 페이지, 가족 그림, og.png(링크 미리보기).
